# Retail Sales Analysis

## 📊 Project Overview

This project analyzes retail sales data using MySQL and Power BI to identify sales trends, customer patterns, product category performance, and key business insights.

## 🛠️ Tools Used

- MySQL
- Power BI
- CSV Dataset

## 📌 Key Analysis

- Total Revenue
- Total Transactions
- Total Quantity Sold
- Average Order Value
- Monthly Sales Trend
- Gender-wise Sales
- Category-wise Sales
- Age Group-wise Sales
- Quantity by Product Category

## 📈 Dashboard

The Power BI dashboard provides an interactive view of retail sales performance with date, category, and gender filters.

## 🔍 SQL Analysis

SQL was used for:

- Data exploration
- Data cleaning checks
- Aggregate calculations
- Category-wise analysis
- Monthly sales analysis
- Top transaction analysis

## 💡 Key Insights

- Electronics generated the highest category sales.
- Clothing had the highest quantity sold.
- The 50+ age group contributed the highest sales.
- Monthly sales varied throughout the year.

- `retail_sales.csv` — Dataset
- `Retail_Sales_Analysis.pbix` — Power BI dashboard
